# Note Check

A camera-based screening tool for Australian polymer banknotes. Flags supported serial patterns and issue features for a closer look; it does not estimate value.

Camera images are processed on the device. The reader downloads on first use. Verify the serial, denomination and design before relying on a result.

## GitHub Pages

In Settings → Pages, select Deploy from a branch, then main and / (root). Save. Open the published HTTPS address on your phone and allow camera access.

## Limitations

A result covers the supported screening rules only. Condition, printing errors, counterfeit detection and all collectable varieties are outside this version.

Third-party OCR model and runtime notices and licenses are in the ocr folder.
